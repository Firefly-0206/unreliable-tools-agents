# Direction of repeat errors (MMI-direction hypothesis)

Generated by `bench/analyze_repeat_direction.py` from existing answer files; no model calls. PR = re-query of an already used persistent source (`query_same_source`), TR = re-call of the per-call-independent tool. Rates are task-level means with 95% bootstrap CIs over base tasks; reference policies (`mmi`, `fault_unaware`) are evaluated on the same tasks as the model/condition in each block. Definitions are in the script docstring.

### Do the LLM's errors coincide with the reference policies' errors?

Agreement = share of the LLM's answers falling in the same action category as the policy's, on tasks where the policy is wrong (vs right). The first agreement columns are dominated by the LLM's accuracy (a model that is mostly right cannot agree with a wrong policy); the 'share of the LLM's wrong answers' columns are accuracy-free: among the LLM's wrong answers on tasks where the policy is wrong, the fraction in the policy's wrong category, with the share expected if the LLM picked uniformly among the available non-optimal categories in brackets. Error mix = distribution of the chosen category among wrong answers.
